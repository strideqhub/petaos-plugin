# 支付管理操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[支付管理](https://petaos.tech/pay/app)；或官网 Console → PETAOS Apps → 支付管理。

适用角色：支付运维、财务管理员。

前置条件：有支付应用及订单查询权限；知道业务订单号、支付渠道和环境。

重要边界：支付管理是底层支付运维，面向客户的收款用 PayLink。案例页面也可能调用真实渠道，不当作免费沙箱。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-pay-01"></a>

### pay-01｜定位支付和回调状态

入口：[打开页面](https://petaos.tech/pay/order)。

前置条件：准备业务订单号或支付订单号及查询时间。

操作步骤：

1. 在支付订单按应用、订单号、状态和时间筛选。
2. 打开目标订单，核对金额、渠道、业务关联与支付结果。
3. 到回调通知查相同业务关联，区分支付成功与业务通知成功。
4. 异常交给支付运维核查；重发通知前确认业务接收端支持去重。

完成依据：支付记录与业务订单对应，通知结果有可追溯记录；两者状态分别记录。

异常/停止条件：通知失败不等于未支付，禁止让客户盲目重复付款。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-pay-02"></a>

### pay-02｜核对退款、转账与钱包

入口：[打开页面](https://petaos.tech/pay/refund)。

前置条件：有受限财务查看权限；准备原支付单和业务退款申请。

操作步骤：

1. 在退款订单查原支付与退款记录，核对金额和状态。
2. 涉及转账时到转账订单定位收款对象、渠道状态与关联单。
3. 在钱包余额查看账面余额与流水；充值套餐仅由授权人员维护。

完成依据：每条退款/转账可关联业务依据；余额与流水可解释。

异常/停止条件：本技能不代替执行退款、提现或转账；资金操作交由有权人员完成。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

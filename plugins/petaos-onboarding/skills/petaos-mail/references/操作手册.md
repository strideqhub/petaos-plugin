# 邮件协作操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[邮件协作](https://petaos.tech/mail/dashboard)；或官网 Console → PETAOS Apps → 邮件协作。

适用角色：邮箱管理员、协作主管。

前置条件：拥有域名及邮箱配置授权；准备使用者账号和合法的邮件服务配置。

重要边界：本应用主要是邮件协作管理，不把系统短信/邮箱模板管理混为一处。SMTP 密码由用户安全录入，不收集到手册。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-mail-01"></a>

### mail-01｜接入企业域名、邮箱和席位

入口：[打开页面](https://petaos.tech/mail/domain)。

前置条件：已获域名配置与账号开通授权；域名管理员可配置 DNS。

操作步骤：

1. 添加域名，选择类型与主域名设置，按页面提示到域名服务商配置要求的记录。
2. 回到域名管理点击校验，确认校验结果后再继续。
3. 邮箱账号新建邮箱，核对邮箱地址、显示名、出站通道、使用者、共享与默认设置。
4. 席位成员分配使用者、角色、时区和语言；共享邮箱权限按最小范围配置。

完成依据：域名显示验证结果、账号启用、席位归属正确；实际收发还需指定测试收件人验证。

异常/停止条件：本次看板已验证域名为 0，不能宣称已经能收发邮件。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-mail-02"></a>

### mail-02｜配置规则与假期自动回复

入口：[打开页面](https://petaos.tech/mail/rule)。

前置条件：明确邮箱账号编号、匹配条件、动作和是否停止后续规则。

操作步骤：

1. 新增规则，填写账号、规则名称、优先级、条件 JSON 和动作 JSON；只使用系统接受的结构。
2. 复核停止后续与状态，避免循环转发或大范围邮件移动。
3. 假期自动回复输入账号编号并加载配置，填写主题、正文、开始/结束日期与启用状态。
4. 确认实际影响的邮箱和时间范围后保存，使用经同意的测试收件人验证。

完成依据：配置重新打开一致；测试邮件只触发预期规则/回复且无循环。

异常/停止条件：JSON 格式或邮件通道错误时先停留在配置检查，不反复发送测试邮件。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

### 邮箱账号

入口：[/mail/account](https://petaos.tech/mail/account)。

前置条件：当前企业已开通此页，操作者拥有此次动作的数据与操作权限。准备业务资料及所需关联记录；正式变更须在当前授权范围内。

操作步骤：

1. 进入“邮箱账号”，先查已有同名/同编号记录，确认当前状态与归属。
2. 选择实际可见的目标操作，核对下列相关字段及必填项；选择已有的关联对象，不凭名称猜编号。
3. 复核预览/详情：新增或编辑仅在用户已要求该变更时保存；审批、执行、发放、发送、删除、授权或启停不能当作保存后的自动下一步。
4. 保存或执行后重新查询同一编号。若动作影响库存、资金、权限或外部消息，必须再查相应流水、审计或投递结果；失败/超时先查结果再重试。

字段索引：邮箱地址、显示名、出站通道、使用者编号、共享邮箱、默认、状态、SMTP 配置、SMTP 密码

操作索引：新建邮箱、编辑、更多、删除、关闭

完成依据：“邮箱账号”的目标记录可重新查询且字段/状态符合此次操作；有外部影响时有独立业务证据，不仅是成功提示。

证据：菜单已核对；页面动作未实操本地页面模板已定位（不等于服务端链路已验证）。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

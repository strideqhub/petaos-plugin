# 电子防盗操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[电子防盗](https://petaos.tech/eas/dashboard)；或官网 Console → PETAOS Apps → 电子防盗。

适用角色：门店防损员、设备管理员。

前置条件：已知门店、设备编码、频率及商品标签；具备设备管理权限。

重要边界：后台登记不证明物理门禁/标签已经工作；消磁会影响实物防盗，须与实际售出记录核对。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-eas-01"></a>

### eas-01｜登记门口设备与防盗标签

入口：[打开页面](https://petaos.tech/eas/gateway)。

前置条件：有实际设备清单，已核对工作频率。

操作步骤：

1. 新建设备，填写编码、名称、类型、工作频率、门店、安装位置与状态。
2. 防盗标签新建标签，填写标签编号、类型、工作频率、绑定商品与状态。
3. 核对设备与标签兼容，并在现场用指定测试标签验证事件。

完成依据：后台设备/标签可查询，且实际现场事件能关联设备和标签。

异常/停止条件：无事件先查设备连接、频率和标签状态，不以后台保存成功替代硬件验收。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-eas-02"></a>

### eas-02｜处理报警并核对消磁

入口：[打开页面](https://petaos.tech/eas/alarm)。

前置条件：有真实报警与现场处置依据；涉及消磁有销售单据。

操作步骤：

1. 按设备、标签和时间定位报警，核对事件详情。
2. 填写处置状态与备注，保留现场调查依据。
3. 需要手动消磁时核对标签、设备、销售订单和出库单，并由授权人员操作。
4. 查看消磁记录与报警关联。

完成依据：处置记录有操作者、时间和理由；消磁记录关联正确售出业务。

异常/停止条件：不能通过删除报警或随意消磁把看板变“正常”。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

入口：[/eas/tag](https://petaos.tech/eas/tag)。

前置条件：当前企业已开通此页，操作者拥有此次动作的数据与操作权限。准备业务资料及所需关联记录；正式变更须在当前授权范围内。

操作步骤：

1. 进入“防盗标签”，先查已有同名/同编号记录，确认当前状态与归属。
2. 选择实际可见的目标操作，核对下列相关字段及必填项；选择已有的关联对象，不凭名称猜编号。

字段索引：标签编号、标签类型、工作频率、绑定商品、状态

操作索引：新建标签、编辑、更多、删除、关闭、保存

完成依据：“防盗标签”的目标记录可重新查询且字段/状态符合此次操作；有外部影响时有独立业务证据，不仅是成功提示。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

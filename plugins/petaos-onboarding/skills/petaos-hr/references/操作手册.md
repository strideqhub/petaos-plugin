# 人力资源操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[人力资源](https://petaos.tech/hr/dashboard)；或官网 Console → PETAOS Apps → 人力资源。

适用角色：HR、部门主管、员工。

前置条件：有最小范围的人事权限；已明确系统员工与 HR 档案关系、薪资国家和时区。

重要边界：工资、身份号码、考勤与银行信息敏感。不要把真实档案粘到培训示例；发薪和人事决策由授权人员完成。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-hr-01"></a>

### hr-01｜建立员工档案与考勤基础

入口：[打开页面](https://petaos.tech/hr/employee)。

前置条件：系统员工已存在；准备直属上级、岗位、工作地点与批准的人事资料。

操作步骤：

1. 配置档案，选择员工并填写上级、办公室、工作地点等必要信息。
2. 职位职级关联已有系统岗位，设置批准的级别和薪资范围。
3. 工作地点核对坐标和打卡半径；HR 设置核对时区、签到签退与围栏校验。
4. 排班管理设置员工、日期、班次与起止时间；公共假日核对国家和日期。

完成依据：档案绑定正确员工，排班和地点可查；员工实际打卡还需经授权现场验证。

异常/停止条件：界面部分“姓名”标签用于配置名称，按表单上下文判断，不机械填个人姓名。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-hr-02"></a>

### hr-02｜请假、报销与薪资处理

入口：[打开页面](https://petaos.tech/hr/leave)。

前置条件：请假类型/额度与薪资期间已由 HR 确认，有该员工操作权限。

操作步骤：

1. 请假申请填写员工、类型、起止日期、总天数与原因，确认后提交。
2. 核对审批结果与考勤记录，不能把提交视为批准。
3. 薪资管理选择周期、起止日期和薪资国家，计算后逐项核对考勤、奖金、扣项与实发。
4. 报销申请检查附件和业务依据；“通过”与“发放报销”分别授权并分别验收。

完成依据：申请有处理记录，薪资计算明细可复核；实际发放须有独立支付证据。

异常/停止条件：不自动跨国套用税率/社保，不代替 HR 或财务做最终决策。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-hr-03"></a>

### hr-03｜用 SOP 和清单完成入职培训

入口：[打开页面](https://petaos.tech/hr/sop)。

前置条件：已有培训正文、责任人和目标员工。

操作步骤：

1. 创建 SOP，填写名称、类别、生效日期与正文，保存后核对版本内容。
2. SOP 指派选择目标员工并确认范围，追踪阅读/完成状态。
3. 入离职清单模板设置类型、状态及清单项；在清单执行选择模板和员工发起。
4. 查看执行进度，把未完成项分配到责任人，不因发起成功就标记培训完成。

完成依据：每位员工的指派、清单项和完成状态可查询；能指出尚未完成内容。

异常/停止条件：离职清单可能涉及账号和权限回收，各项由责任管理员执行，不由培训动作一键推断。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

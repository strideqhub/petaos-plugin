# 会员忠诚操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[会员忠诚](https://petaos.tech/loyalty/dashboard)；或官网 Console → PETAOS Apps → 会员忠诚。

适用角色：会员营销人员。

前置条件：明确会员、积分预算、活动规则和适用品牌。

重要边界：配置券模板或活动不等于已发券。营销推送、积分扣发和跨品牌权益具有外部影响，须明确对象和额度。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-loyalty-01"></a>

### loyalty-01｜配置券与积分奖励

入口：[打开页面](https://petaos.tech/loyalty/coupon)。

前置条件：批准的券面额/折扣、发行量、有效天数和积分成本。

操作步骤：

1. 新增券模板，设置名称、类型、面额/折扣、所需积分、发行量和有效天数。
2. 奖励目录配置类型、积分、库存及关联券模板。
3. 赚分规则设置触发事件、门槛、积分方式/值、倍率及优先级；检查是否与现有规则重叠。
4. 用指定测试会员执行一笔获批的兑换/赚分，再核对会员流水及券记录。

完成依据：规则正确保存；验收时会员积分与实际券/奖励记录一致。

异常/停止条件：保存模板不是发券成功；重复触发风险先查事件去重和已有流水。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-loyalty-02"></a>

### loyalty-02｜准备会员任务、活动与定向触达

入口：[打开页面](https://petaos.tech/loyalty/mission)。

前置条件：目标人群、任务次数、奖励、活动名额/时间已确认。

操作步骤：

1. 会员任务设置类型、目标次数、奖励积分及关联券。
2. 活动票务核对地点、名额、票价和奖励；票券管理按活动和会员查记录。
3. 营销推送设置渠道、受众和内容，先预览后确认执行范围。
4. 联盟品牌或积分商城涉及跨品牌/付费权益时，分别复核品牌、库存、等级和生效期。

完成依据：任务完成、票券发放或推送结果有逐笔记录；名单和预算不超范围。

异常/停止条件：未设置真实支付/通知通道时只验配置，不承诺售票或消息已送达。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

2. 选择实际可见的目标操作，核对下列相关字段及必填项；选择已有的关联对象，不凭名称猜编号。
3. 复核预览/详情：新增或编辑仅在用户已要求该变更时保存；审批、执行、发放、发送、删除、授权或启停不能当作保存后的自动下一步。
4. 保存或执行后重新查询同一编号。若动作影响库存、资金、权限或外部消息，必须再查相应流水、审计或投递结果；失败/超时先查结果再重试。

字段索引：名称、分类、等级要求、封面图、内容、积分价、币价、库存、状态、开始时间、结束时间、抢购名额

操作索引：新建商品、更多、限时抢、查询、取消、确定

完成依据：“积分商城”的目标记录可重新查询且字段/状态符合此次操作；有外部影响时有独立业务证据，不仅是成功提示。

证据：菜单已核对；页面动作未实操本地页面模板已定位（不等于服务端链路已验证）。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

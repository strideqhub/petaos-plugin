# 现场取证操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[现场取证](https://petaos.tech/proof/dashboard)；或官网 Console → PETAOS Apps → 现场取证。

适用角色：现场主管、巡检人员、售后人员。

前置条件：有项目权限；准备项目地点、员工、打卡点与取证规则。

重要边界：定位、照片与外部分享包含个人或现场信息。浏览器位置/相机授权需用户同意；不能伪造到场证据。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-proof-01"></a>

### proof-01｜创建现场项目与检查点

入口：[打开页面](https://petaos.tech/proof/project)。

前置条件：已确认客户、地点和允许打卡范围，准备负责员工。

操作步骤：

1. 点击新增项目或快速创建，填写项目名称、编码、客户和地点。
2. 设置打卡点名称、位置、围栏模式或允许半径；地图服务不可用时不猜坐标。
3. 保存后进入项目详情，添加检查点/检查模板，配置频率与检查项。
4. 通过成员指派把已授权员工加入项目。

完成依据：项目详情能查到地点、检查点、模板和成员；成员看到的项目范围正确。

异常/停止条件：有项目却无法打卡先核对成员指派、检查点状态、位置权限和围栏范围。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-proof-02"></a>

### proof-02｜复核到场证据和考勤

入口：[打开页面](https://petaos.tech/proof/record)。

前置条件：有可查看的到场记录；明确项目、人员、日期。

操作步骤：

1. 筛选项目/日期/人员，打开到场记录详情。
2. 核对时间、地点、照片与检查结论；异常记录记录原因，不替员工造数据。
3. 在考勤页面核对对应人员与日期；人工判定须说明业务依据并获得授权。
4. 确需分享时到分享链接选择项目、标题和过期时间，确认接收对象及披露范围后生成。

完成依据：到场记录与考勤判定可追溯；分享链接权限和到期时间符合授权。

异常/停止条件：后台查看通过不证明现场设备采集成功，设备信任变更单独审批。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-proof-03"></a>

### proof-03｜建立保修计划并处理理赔

入口：[打开页面](https://petaos.tech/proof/warranty/programs)。

前置条件：确认保修产品、月数、凭证要求和条款；有售后权限。

操作步骤：

1. 新建计划，填写产品、保修月数、客服邮箱、需凭证/可转让等规则。
2. 在发码选择计划及方式，填写数量或序列号；生成后在产品项核对批次与编号。
3. 注册页面核对客户注册记录；理赔页面打开申请，核对凭证和适用计划后填写处理状态与意见。

完成依据：计划、产品编号、注册、理赔处理形成可追溯关系。

异常/停止条件：召回公告“发送”会面向客户传播；未确认批次、收件范围和正文不能发送。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

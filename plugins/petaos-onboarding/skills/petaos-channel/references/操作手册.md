# 渠道中台操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[渠道中台](https://petaos.tech/channel/dashboard)；或官网 Console → PETAOS Apps → 渠道中台。

适用角色：客服主管、渠道运营。

前置条件：明确渠道账号、群组、品牌与允许处理的数据；账号/套餐具备所需能力。

重要边界：规则启用、群发、Rich Menu 发布、日报推送、死信重放可能真实发消息。测试台是否有外部副作用以当前说明为准。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-channel-01"></a>

### channel-01｜配置客服知识与回复规则

入口：[打开页面](https://petaos.tech/channel/cs-agent-config)。

前置条件：账号已接入，准备知识库、模型、兜底和转人工策略。

操作步骤：

1. 在渠道账号刷新官方状态并检查连接详情。
2. 群组管理核对账号、群/房 ID、场景和知识库；不要把普通群与 OpenChat 混用。
3. 客服 AI 策略设置所属账号、回复模式、模型、知识库、检索参数、兜底与 handoff 话术。
4. AI 自动回复规则填写规则名、触发词与匹配方式；先保持待确认状态，在测试台用模拟问题检查命中结果。
5. 确认启用范围后再启用；到回复审计与消息检索核对结果。

完成依据：规则在正确账号/群组命中，兜底与转人工可解释，审计可找到对应请求。

异常/停止条件：没有知识来源时不要让 AI 编业务承诺；查看工单转人工。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-channel-02"></a>

### channel-02｜处理升级工单与控制群发

入口：[打开页面](https://petaos.tech/channel/ticket)。

前置条件：有工单处理权限，明确客户和坐席；外发内容已经业务审核。

操作步骤：

1. 打开工单核对摘要、分类、优先级和原始上下文，分配受理人。
2. 坐席回复前核对接收对象；提交后到回复审计检查发送结果。
3. 群发需要先维护出站素材，再选渠道、标签或指定用户，预览变量替换。
4. 保存群发任务与执行发送分开处理；取得具体任务的发送确认后执行。

完成依据：工单状态与处理记录一致；群发按对象有成功/失败结果，不以任务创建代替发送成功。

异常/停止条件：死信重放可能重复副作用，先确认目标与下游去重，不批量盲重放。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-channel-03"></a>

### channel-03｜核对电商平台接入条件

入口：[打开页面](https://petaos.tech/channel/marketplace)。

前置条件：店铺管理人员批准接入；平台桥接、密钥和回调已完成验收。

操作步骤：

1. 读取平台桥接状态；提示未启用时停在配置准备阶段。
2. 在店铺账号核对平台、ERP 归属和授权状态。
3. 商品映射核对平台 SKU 与内部商品；平台订单核对 ERP/WMS 关联。
4. 事件与任务中检查最后同步、错误和重试，选择一条授权测试订单做验收。

完成依据：只有店铺授权、SKU 映射、订单/库存/履约事件均有证据才称接入完成。

异常/停止条件：本次平台桥接未启用，不能写成 Shopee/Lazada 已可同步。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

# CRM 系统操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[CRM 系统](https://petaos.tech/crm/dashboard)；或官网 Console → PETAOS Apps → CRM 系统。

适用角色：销售、销售主管、客户成功。

前置条件：有客户数据范围；准备客户来源、联系人、商机阶段及归属规则。

重要边界：客户公海、转移负责人会改变访问范围；电子合同签署是独立法律动作，不能由培训自动接受。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-crm-01"></a>

### crm-01｜从线索建立客户与商机

入口：[打开页面](https://petaos.tech/crm/clue)。

前置条件：有获准录入的客户信息，明确销售负责人。

操作步骤：

1. 线索管理先按姓名/联系方式/来源查重，再新建或继续跟进已有线索。
2. 在客户管理核对客户名称、来源、负责人、行业/级别及联系方式；根据页面提供的转化入口或业务规则处理线索，不重复建客户。
3. 联系人关联正确客户；商机选择客户、阶段、预计成交金额/时间和产品等页面字段。
4. 记录跟进事项与下次时间，到待办事项核对任务。

完成依据：线索/客户/联系人/商机关系正确，负责人与跟进记录可查询。

异常/停止条件：客户公海领取/转移前确认数据归属；同名不等于同一客户。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-crm-02"></a>

### crm-02｜合同、回款计划与实际回款

入口：[打开页面](https://petaos.tech/crm/contract)。

前置条件：商机/客户已确认，有批准的合同内容与金额。

操作步骤：

1. 创建或打开合同，核对客户、产品、金额及合同日期，按实际审批规则提交。
2. 合同审批后建立回款计划，设置期次、日期和金额。
3. 实际回款管理核对收款凭据并关联相应合同/计划。
4. 查看业绩/客户分析时保持相同人员、日期和统计口径。

完成依据：合同状态、计划余额和实际回款有明细依据；计划不等于已到账。

异常/停止条件：不能把 ERP 收款、PayLink 交易和 CRM 回款视为自动互通，须核对实际关联记录。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-crm-03"></a>

### crm-03｜生成电子合同并追踪签署

入口：[打开页面](https://petaos.tech/crm/econtract)。

前置条件：已有已审批 CRM 合同；签署人、收件地址、合同正文与签署方式经过审核。

操作步骤：

1. 打开电子合同工作台，确认普通签名与合格签名通道状态。
2. 从已审批 CRM 合同新建电子合同，核对冻结副本、签署参与者和验证设置。
3. 发送前确认具体收件人及正文；用户本人完成签署/接受协议。
4. 根据时间线查看发送、验证、签署与最终状态。

完成依据：冻结正文与批准合同一致，所有必需签署人的记录齐全且状态完成。

异常/停止条件：本次合格电子签名通道未启用；不得将普通电子签名称作已启用的合格签名。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

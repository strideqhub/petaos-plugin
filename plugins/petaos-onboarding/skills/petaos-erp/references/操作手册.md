# ERP 系统操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[ERP 系统](https://petaos.tech/erp/dashboard)；或官网 Console → PETAOS Apps → ERP 系统。

适用角色：采购、销售、财务、仓储主管。

前置条件：有对应业务权限；准备产品、单位、分类、供应商/客户、仓库和结算账户。

重要边界：ERP 商务单据与 WMS 仓库执行分工不同。保存、审核、入出库和资金收付分别核验，不能重复登记库存。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-erp-01"></a>

### erp-01｜创建采购订单

入口：[打开页面](https://petaos.tech/erp/purchase/order)。

前置条件：供应商和产品已建立；采购时间、数量、单价、税与折扣已确定。

操作步骤：

1. 进入采购订单点击 Add；Order No. 自动生成，填写必填 Order Time 和 Supplier。
2. 点击 + Add Purchase Product，选择产品并核对单位、Requested Delivery、Quantity、Unit Price、Tax Rate。
3. 核对行金额、含税合计及折扣；选择 Settlement Account，Deposit Paid 只填写有依据的已付订金。
4. 复核附件与备注，点击 Confirm 保存后，按订单号重新查询。

完成依据：订单号、供应商、明细与总额可重开核对；此时不代表已审批、已入库或银行已付款。

异常/停止条件：数量/税率不对先修订单；超时先查订单，不重复创建。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-erp-02"></a>

### erp-02｜采购入库、退货和付款闭环

入口：[打开页面](https://petaos.tech/erp/purchase/in)。

前置条件：已有可用采购订单、实际收货数据和仓库；明确是否由 WMS 执行。

操作步骤：

1. 采购入库新建并关联订单，核对供应商、仓库、实际数量和可入数量。
2. 按系统提供的审核/执行流程处理；若任务交给 WMS，到 WMS 查对应业务单号，不再手工重复入库。
3. 退货在采购退货关联原单，核对数量、原因与退款金额。
4. 付款单选择供应商和结算账户，关联采购入库/退货，财务复核后处理。

完成依据：原订单、入库/退货、库存流水及应付款关联一致；实际银行付款另验。

异常/停止条件：只有订单没有收货不记入库；发生退货不能直接删原采购单。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-erp-03"></a>

### erp-03｜销售订单、出库与收款

入口：[打开页面](https://petaos.tech/erp/sale/order)。

前置条件：客户、产品、售价和可用库存已确认。

操作步骤：

1. 新建销售订单，核对 Customer、Salesperson、Order Time、商品数量单价和折扣。
2. 确认业务审批状态后，在销售出库关联订单并核对仓库、实际发货数量与费用。
3. 若 WMS 履约，在出库管理按业务单号追踪拣货/完成，不在两边重复出库。
4. 收款单关联销售出库/退货并核对实际金额；售后按原订单记录请求。

完成依据：销售订单、实际出库、库存流水、收款记录逐笔可追溯。

异常/停止条件：出库单保存不证明客户收到货；收款单保存不证明通道资金到账。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-erp-04"></a>

### erp-04｜维护价目表与客户门户范围

入口：[打开页面](https://petaos.tech/erp/product/price-list)。

前置条件：有定价批准；目标客户与外部身份可见范围明确。

操作步骤：

1. 新增价目表，填写编码、名称、类型、适用客户、生效/失效时间与优先级。
2. 添加产品与数量阶梯，核对最低数量和价格，检查重叠期及状态，保存后重新查询。
3. 进入客户门户先选择 ERP 客户；只配置该客户外部身份可见范围，避免暴露其他客户票据/订单。
4. 由对应客户测试账号验证报价、订单、履约与票据访问边界。

完成依据：价目表匹配预期产品/数量/期间；客户门户只能看到获准客户数据。

异常/停止条件：本次仅查看门户初始页；未为任何客户开通外部权限。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

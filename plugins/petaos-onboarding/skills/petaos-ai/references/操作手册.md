# AI 大模型操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[AI 大模型](https://petaos.tech/ai/dashboard)；或官网 Console → PETAOS Apps → AI 大模型。

适用角色：业务使用者、知识管理员、AI 管理员。

前置条件：有可用模型、额度和数据授权；明确任务是否需访问外部数据。

重要边界：AI 生成会消耗额度且可能出错。API 密钥由管理员安全录入；知识库上传先确认数据与模型服务可处理范围。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-ai-01"></a>

### ai-01｜建立知识库并验证检索

入口：[打开页面](https://petaos.tech/ai/knowledge)。

前置条件：可用 Embedding Model，资料获准上传与处理。

操作步骤：

1. 新增知识库，设置名称、描述、Embedding Model、Retrieval topK、Similarity Threshold 和状态。
2. 进入文档添加获准文件，按步骤配置分段，Preview Segments 检查切分。
3. Save and Process 后等待具体文档处理完成，不能把上传成功当作索引成功。
4. 检索测试用资料中有答案的问题，核对命中片段与来源；再用无答案问题检查边界。

完成依据：文档处理状态完成且检索能命中正确原文，引用可追踪。

异常/停止条件：无命中先查文档状态、分段、模型与阈值，不能靠编造答案补齐。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-ai-02"></a>

### ai-02｜创建 AI 处理工作流

入口：[打开页面](https://petaos.tech/ai/workflow)。

前置条件：明确输入、输出和可用聊天模型；不是创建审批申请。

操作步骤：

1. Add 进入已有两步页面：Basic Info 与 Workflow Design。
2. 填写 Workflow Code、Workflow Name、Status 和 Remark。
3. 在设计器添加所需节点、输入输出、参数与连接，选择真实可用模型。
4. 先用 Test / Run Workflow 测试模拟输入，检查各节点输出；获得额度和执行授权后才运行。
5. Save 保存并重新打开核对；对多组输入记录预期与实际结果。

完成依据：图可重开，测试运行有可追溯输出且满足验收；不凭保存成功宣称业务自动化已联通。

异常/停止条件：当前源码知识库/内部能力选择提供方存在空列表，不能承诺所有设计器节点已接入实际业务。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-ai-03"></a>

### ai-03｜使用对话与内容生成并控制费用

入口：[打开页面](https://petaos.tech/ai/chat)。

前置条件：有允许使用的模型/角色；已获本次数据处理与费用授权。

操作步骤：

1. New Conversation 选择合适角色和模型，确认上下文与回复 Token 限额。
2. 输入脱敏业务问题，核对答案和来源；不确定时明确转人工。
3. 写作、绘画、音乐或思维导图按各自页面填写主题/参数，生成后人工复核再使用。
4. 到 AI Usage Dashboard 核对本次用量；有权限的管理员可在对应管理页追踪记录。

完成依据：输出符合需求且来源可核对；用量可解释；对外发布须独立确认。

异常/停止条件：没有可用模型或额度时报告配置缺口，不尝试从其他账号取密钥。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

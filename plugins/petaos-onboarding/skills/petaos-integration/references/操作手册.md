# 第三方集成操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[第三方集成](https://petaos.tech/integration/google-dashboard)；或官网 Console → PETAOS Apps → 第三方集成。

适用角色：集成管理员、实施人员。

前置条件：有第三方连接授权；明确数据范围、目标系统、接收端与凭证管理责任人。

重要边界：连接成功不等于业务同步成功。第三方 OAuth、共享范围、凭证引用和外部推送都须限定具体对象。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-integration-01"></a>

### integration-01｜连接 Google 并同步知识资料

入口：[打开页面](https://petaos.tech/integration/google-dashboard)。

前置条件：用户允许连接指定 Google 账号与文件范围；有目标知识库。

操作步骤：

1. 查看 Google 连接状态；未连接时由用户完成 OAuth，并核对实际授权范围。
2. 在同步规则中新建/编辑规则，指定允许的文件夹、目标知识库、名称与状态。
3. 使用 Drive 文件预览检查文件夹 ID、文件类型和目标内容，避免选择整个私人云盘。
4. 在授权后执行同步，检查每条规则和文档的处理结果，再到知识库做检索测试。

完成依据：连接状态、同步规则、已处理文档和检索命中四项对应。

异常/停止条件：本次只查看未连接界面，没有连接账号、授权文件或运行同步。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-integration-02"></a>

### integration-02｜建立业务 Webhook 并验收投递

入口：[打开页面](https://petaos.tech/integration/webhook)。

前置条件：接收端 HTTPS、事件范围、签名校验与去重已由双方确认。

操作步骤：

1. 查看接收端签名验证说明；创建订阅前明确事件类型与目标地址。
2. 在新建订阅配置范围；密钥只在创建/轮换时显示一次，由管理员安全保存，不写入聊天或手册。
3. 以授权测试业务产生事件，在投递记录查看事件、状态、HTTP 结果和重试次数。
4. 只有死信允许人工重放；重放前确认下游去重与此次副作用。

完成依据：目标事件存在成功投递且接收端有相同事件处理证据；不能只看 HTTP 200 就宣称业务入账。

异常/停止条件：停用订阅会取消未完成投递，培训中不随意切换生产订阅。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-integration-03"></a>

### integration-03｜检查银行/政府适配器上线状态

入口：[打开页面](https://petaos.tech/integration/external-adapter)。

前置条件：桥接服务、凭证引用审批和责任人已明确。

操作步骤：

1. 读取桥接状态；未启用或配置不完整时不发起真实业务。
2. 连接器页核对名称、领域、凭证引用、限流与状态。
3. 任务页查具体业务交接、重试结果；审计页保留授权和执行证据。

完成依据：连接测试与指定业务任务分别验收，能追溯凭证引用及审计。

异常/停止条件：本次桥接未启用或配置不完整；不能承诺真实银行/政府申报已连通。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

入口：[/integration/webhook](https://petaos.tech/integration/webhook)。

证据：页面已查看；未创建订阅或触发事件。本地页面模板未定位；步骤仅基于当前可见页面，未展开的操作需现场复核。

## 故障处理与培训验收

- 找不到入口：先核对当前企业、应用选择、角色和套餐；不通过猜 URL 绕过权限。
- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。
- 保存后超时：记录时间和业务编号，先查是否已创建/执行，确认结果后再重试。
- 按钮禁用：阅读状态限制；已完成/作废记录应走更正流程，不能删流水解决。
- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
- 培训验收：记录任务 ID、角色、环境、业务编号、操作前后状态、验证页、结果及未完成项。只把有业务证据的操作判为完成。

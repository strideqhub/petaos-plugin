# 商城系统操作手册

版本：2026-09-14 · 客户培训初版（非全链路认证）

插件版请先读 [使用边界与验证状态](../../petaos-start/references/使用边界与验证状态.md)。本文是编写时快照，历史观察不代表当前租户状态；实际操作以当前页面为准。

## 入口与适用范围

入口：[商城系统](https://petaos.tech/mall/home)；或官网 Console → PETAOS Apps → 商城系统。

适用角色：商城运营、订单客服。

前置条件：具备商城权限；已确认商品、规格、库存、配送、售后与支付配置。

重要边界：商品上架、促销、发货、退款和客服发送会影响真实顾客。商城积分活动与独立 Loyalty 配置不要混淆。

本册复用当前网站，不创建第二套业务页面。未实际提交生产业务；下列完成依据是客户操作后的验收标准，不是本次测试已通过的声明。

## 培训任务

<a id="task-mall-01"></a>

### mall-01｜准备商品并核对上架条件

入口：[打开页面](https://petaos.tech/mall/product/spu)。

前置条件：分类、品牌、属性、价格、库存与图片内容已获批准。

操作步骤：

1. 先维护商品分类、品牌和属性；商品列表新建商品，填写基础信息与规格。
2. 逐个 SKU 核对价格、库存、重量/物流及商品描述，确认分类与属性值。
3. 在交易配置和配送管理检查运费与配送基础设置。
4. 保存后预览商品；取得上架授权后再调整上架状态。

完成依据：商品详情与 SKU 数据一致；面向顾客的可见性和价格单独验收。

异常/停止条件：后台保存不代表店铺前台已上架，勿用空库存或演练价格发布生产商品。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-mall-02"></a>

### mall-02｜处理订单与售后退款

入口：[打开页面](https://petaos.tech/mall/trade/order)。

前置条件：已有真实或授权测试订单；核对订单身份、支付状态与库存。

操作步骤：

1. 订单列表按订单号/顾客/状态查找，打开详情核对商品、金额和配送信息。
2. 按实际履约进度处理发货并核对物流单号，不虚报已发货。
3. 售后退款定位原订单、退款原因、退货数量与凭据，由有权人员决策。
4. 完成后分别查看订单、售后、物流和支付退款状态。

完成依据：订单履约与售后记录有真实依据；退款成功须以支付结果为准。

异常/停止条件：不能将售后审核通过等同资金已退回；涉及实际退款交由授权人员完成。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

<a id="task-mall-03"></a>

### mall-03｜配置营销并评估结果

入口：[打开页面](https://petaos.tech/mall/promotion/coupon/template)。

前置条件：有批准的折扣/名额/时间/库存，确认不与现有活动冲突。

操作步骤：

1. 优惠券或对应秒杀/拼团/砍价/积分活动页创建活动，核对商品与适用人群。
2. 检查生效期、优惠条件、数量限制和库存，先保存预览再授权上线。
3. 商城装修与内容管理仅修改本活动需要的内容，检查页面链接。
4. 用会员、商品和交易统计检查同一期间指标，不能仅看曝光判断成交。

完成依据：活动条件、前台展示与实际订单优惠一致；统计范围明确。

异常/停止条件：当前拼团入口路由含 acitivity 拼写，使用现有菜单，不自行改成猜测地址。

证据状态：结合现有页面、表单/源码编写；保存、发布、审批、支付、外发等业务后果均未在本次执行。

- 找不到记录：重置筛选并查编号、日期、状态、归属；不自动重复创建。

- 需要支持：提交脱敏页面路径、动作、时间、错误和业务编号后几位；不提交密码、Token 或个人档案。
